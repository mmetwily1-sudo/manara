# الجولة 53 — سلوك وإنذارات وإيقاف مؤقت

## المنفذ (3 ميزات)
1. **سجل السلوك**: ترحيل `040` (ملاحظات + إيقاف) + API + قسم بملف الإنجاز.
2. **إنذارات متدرجة**: شفهي/كتابي/نهائي من العد + زر إنذار واتساب لولي الأمر.
3. **الإيقاف المؤقت**: بتاريخ + فك + منع من التحضير والامتحانات والتسجيل الذاتي + شارة.

## التحقق الحي
- الترحيل Success. `tsc` نظيف؛ بناء ناجح؛ behavior=401، suspend=405 (POST فقط) (لا 500).
