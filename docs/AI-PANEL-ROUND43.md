# الجولة 43 — نقل طالب/موظف + مقارنة فروع موسعة

## المنفذ (3 ميزات)
1. **نقل طالب**: `POST /api/students/transfer` (فحص سعة + تعطيل القديم + تسجيل جديد + تدقيق من/إلى) + زر نقل 🔀 بصفحة الطلاب.

3. **مقارنة فروع موسعة**: حضور 7 أيام لكل فرع بتقارير الربحية.
