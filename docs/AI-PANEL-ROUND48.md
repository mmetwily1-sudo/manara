# الجولة 48 — تقسيط + عربون + استرداد

## المنفذ (3 ميزات)
1. **التقسيط**: `POST /api/invoices/installments` — N فواتير شهرية متتالية تعمل مع التذكير والتحصيل القائمين + نموذج بالفواتير.
2. **العربون**: `POST /api/invoices/deposit` — فاتورة حجز مقعد تُخصم FIFO تلقائياً + نموذج.
3. **الاسترداد**: ترحيل `036` (+ عمود ملاحظة الفاتورة) — طلب من صف التحصيل + اعتماد/رفض المالك (الاعتماد يلغي الدفعة من الإجماليات) + تدقيق.

## التحقق الحي
- الترحيل Success. `tsc` نظيف (بعد إصلاح `</tr>` ناقص قديم)؛ بناء ناجح؛ refunds وinstallments =401 (لا 500).
