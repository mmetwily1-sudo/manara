# الجولة 90 — واجبات علاجية تلقائية

## المنفذ
1. **الرصد**: `POST /api/assignments/auto-remedial` (المتعثر = بلا تسليم في 2 من آخر 3 واجبات أو متوسط امتحانات < 50) — ينشئ واجب "خطة علاجية 🩹" مستحق خلال 7 أيام مسمى فيه الطلاب، أو يعلن عدم وجود متعثرين.
2. **الواجهة**: بطاقة التوليد في صفحة الواجبات (مجموعة + زر).

## التحقق الحي
- `tsc` نظيف.
