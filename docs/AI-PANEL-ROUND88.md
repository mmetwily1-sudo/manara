# الجولة 88 — اقتراح رد تلقائي للشكاوى

## المنفذ
1. **القواعد**: `GET /api/complaints/suggest?id=` (معلم: اقتراح حسب النوع — شكر للاقتراحات — وقواعد كلمات للمصاريف/الحضور/الامتحانات/المعلم + اسم الطالب ورقم تذكرة، ورد عام احتياطي).
2. **الواجهة**: زر ✨ في قسم الشكاوى يملأ الرد المقترح قبل الإغلاق.

## التحقق الحي
- `tsc` نظيف.
