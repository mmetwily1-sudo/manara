# الجولة 65 — تنافس الفروع

## المنفذ
1. **نقاط الفروع**: جدول `branch_points` (049: فرع + شهر + نقاط + سبب) + `GET /api/branches/contest` (ترتيب تنازلي + علامة مالك) + `POST` (منح نقاط 1-1000، مالك فقط).
2. **الواجهة**: قسم `BranchContest` في الليدربورد (شهر + أشرطة + ميداليات + نموذج منح للمالك).

## التحقق الحي
