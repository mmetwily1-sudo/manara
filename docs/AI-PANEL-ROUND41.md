# الجولة 41 — QR دوّار + تغييب جماعي + سعة قاعات

## المنفذ (3 ميزات)
1. **QR جلسة دوّار + تسجيل ذاتي**: ترحيل `032` (سر + انتهاء 90 ثانية) + تدوير + صفحة `/a/[id]` (مطابقة لاحقة بطاقة + قيد نشط + نقاط) + مكون عرض بعدّاد.
2. **تغييب جماعي**: زر "تغييب الكل" بتأكيد بجانب "تحضير الكل" (نفس طابور الأوفلاين).
3. **سعة المجموعات**: حد أقصى + منع التسجيل/الاستيراد عند الامتلاء (409) + شارة "مكتملة 🔴" + ضبط من الصفحة.
