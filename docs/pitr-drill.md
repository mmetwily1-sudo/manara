# تدريب الاستعادة الربع سنوي (PITR) — دليل التنفيذ

## المتطلبات المسبقة (بيد المالك، مرة واحدة)
1. خطة Supabase مدفوعة على مشروع الإنتاج (PITR غير متاح في المجانية — تحقق من Dashboard → Settings → Billing).
2. مشروع Supabase **منفصل** للتدريب (يسمى `manara-restore-drill`) — لا تُنفذ الاستعادة على الإنتاج أبداً.

## خطوات التدريب (كل ربع سنة)
1. من مشروع الإنتاج: Dashboard → Database → Backups → اختر نقطة زمنية → Restore to new project → وجّهها لمشروع التدريب.
2. سجّل وقت بدء الاستعادة ووقت جاهزية المشروع (RTO الفعلي).
3. على مشروع التدريب شغّل استعلامات التحقق:
   ```sql
   select count(*) from tenants;
   select count(*) from users;
   select count(*) from payments where status='confirmed';
   ```
   وقارنها بأرقام الإنتاج وقت نقطة الاستعادة (RPO الفعلي = الفارق الزمني).
4. احذف مشروع التدريب بعد التوثيق (توفيراً للتكلفة).

## ما يُنفذ آلياً قبل كل تدريب
`node scripts/db-backup-proof.cjs` — يثبت أن خط القراءة/الاعتماد يعمل end-to-end
(يقرأ كل الجداول + يعد الصفوف + لقطة أعمدة). يجب أن يطبع `BACKUP-PROOF: PASS`.
