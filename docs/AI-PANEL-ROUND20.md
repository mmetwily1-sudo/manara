# الجولة 20 — عودة المنتهية تجربتهم + نسخ امتحان + اتجاه NPS

## السؤال
ماذا نبني أولاً لاستعادة المشتركين المنتهية تجربتهم؟
- (أ) نسخ امتحان بأسئلته كمسودة — Grok + Claude
- (ب) بانر عودة + تجديد ذاتي — Grok + ChatGPT ✅ الفائز (2-1)
- (ج) قراءة بيانات NPS والتصرف — ChatGPT (نُفذ جزئياً: اتجاه شهري)

## المنفذ (مرتباً: ب → أ → ج)
1. **(ب) عودة ذاتية**: `TrialBanner` المنتهي → `/pricing?plan=pro&expired=1`؛ صفحة الأسعار تدعم `?plan=starter|pro|scale` (تمييز "مختارة لعودتك ✅") + بانر "رجعت في الوقت المناسب — بياناتك محفوظة" عند `expired=1`.
2. **(أ) نسخ امتحان**: `POST /api/exams/[id]/duplicate` — نسخة بعنوان مخصص، نفس الأسئلة والمدروجات، `is_published=false` (مراجعة بشرية إلزامية)، عزل `tenant_id`، صلاحية `R.content`، تدقيق `exam:duplicate`؛ زر "نسخ 📋" بصفحة الامتحانات. (وُجدت نسختان متضاربتان clone/duplicate — وُحدتا على duplicate وحُذفت الفارغة.)
3. **(ج) اتجاه NPS**: بطاقة "اتجاه NPS الشهري 📈" بلوحة `/admin/feedback` (متوسط آخر 6 أشهر + ألوان حدّية).
