# الجولة 58 — وضع آمن + وقت إضافي + تصحيح مقالي

## المنفذ (3 ميزات)
1. **التسليم التلقائي**: 3 تبديلات تبويب = تسليم فوري + تحذيرات متدرجة (أصفر/أحمر).
2. **وقت إضافي فردي**: `PATCH codes` (+15د حتى 120، تدقيق، يمنع بعد التسليم) + صفحة إدارة أكواد.
3. **تصحيح المقالي**: قائمة محاولات بأسئلة غير آلية + درجة معتمدة + تدقيق + صفحة.

## التحقق الحي
- `tsc` نظيف؛ بناء ناجح؛ grading=401، الصفحة=200 (لا 500).
