# الجولة 31 — تقارير الربحية (فرع/مدرس/مجموعة)

## المنفذ (3 ميزات في حزمة واحدة)
1. **ربحية الفروع**: محصّل/طلاب/متبقي لكل فرع.
2. **ربحية المدرسين**: مجموعات/طلاب/محصّل لكل مدرس.
3. **ربحية المجموعات**: متوقع (رسوم×طلاب) مقابل محصّل + نسبة تحصيل + متبقي — جدول + طباعة.
- `GET /api/reports/profitability` (مالك) + صفحة `/dashboard/reports`.

## التحقق الحي
- `tsc` نظيف؛ بناء ناجح؛ `/api/reports/profitability`=401 (لا 500).
