# الجولة 44 — خطة الطالب: ترتيب نسبي + متوسط + دروس متأخرة

## المنفذ (3 ميزات)
1. **الترتيب النسبي**: `#N من M` بصفحة تقدم الطالب.
2. **متوسط المجموعة**: نقاطك مقابل المتوسط + تنبيه عند التأخر عنه.
3. **الدروس المتأخرة + خطوات الأسبوع**: أضعف 3 دروس من الامتحانات <60% + خطوات مراجعة.
- `GET /api/me/plan` (جلسة الطالب) + قسم `MyPlanSection` بالتقدم.

## التحقق الحي
- `tsc` نظيف؛ بناء ناجح؛ `/api/me/plan`=401 (لا 500).
