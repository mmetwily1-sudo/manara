# الجولة 93 — مفاتيح API للمطورين

## المنفذ
1. **المفاتيح**: `api_keys` (069: hash فقط + إلغاء + آخر استخدام) + `/api/developers/keys` (إصدار يظهر مرة واحدة — مالك فقط).
2. **البوابة**: `GET /api/public/summary?key=` (ملخص السنتر: الاسم + الفروع + المجموعات + المميزون — يرفض المفتاح الخطأ 401 ويحدث آخر استخدام) + إدارة المفاتيح في الإعدادات.

## التحقق الحي
- `tsc` نظيف؛ summary بدون مفتاح=401 (متوقع).
