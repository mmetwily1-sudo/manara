# الجولة 85 — تصدير بياناتي وحذف حسابي

## المنفذ
1. **التصدير**: `GET /api/me/export` (طالب فقط: بروفايل + قيود + فواتير + مدفوعات + تسليمات + محاولات) + زر تنزيل JSON في `/progress`.
2. **الحذف الآمن**: `POST /api/me/delete` بتأكيد حرفي + منع عند وجود ديون + إخفاء هوية + إنهاء الأجهزة + حذف الدخول + تدقيق.

## التحقق الحي
- `tsc` نظيف.
